## P2-06 — typed bounded REST transport

- `GitHubREST` pins `X-GitHub-Api-Version`, uses explicit API-root URLs, direct
  HTTP, bounded response reads, stable typed status errors, request IDs,
  `Retry-After`/rate-limit metadata, pagination links, and conditional ETag
  reads.
- Repository responses and errors never retain response bodies. Oversized
  bodies fail closed with `ErrResponseLimit`.
- Exact repository identity, visibility, and ref SHA postconditions are
  checked before success is returned. Git object pushes remain delegated to the
  existing exact `Pusher` port. A durable `RepositoryTransaction` regression
  proves a lost local-attach response is retried without a second hosted create.
  A REST publication regression also proves the exact owner/name/ref/SHA tuple
  reaches the pusher and is confirmed afterward.

## P2-07 — explicit provider identity

- `ProviderIdentity` binds the API host, authenticated account, and owner.
- Repository mutation verifies `/user` account identity and rejects a
  different owner before creating or attaching a repository.
- The constructor has no environment-variable or `gh`-config fallback, so
  ambient `GH_TOKEN`/`GITHUB_TOKEN` cannot select a destination. The contract
  matrix covers account mismatch, wrong configured host, wrong token-source
  host, forbidden/rate-limited responses, and revoked App credentials.

## P2-08 — GitHub App installation token source

- `GitHubAppTokenSource` signs short-lived RS256 assertions in memory and
  requests installation tokens with explicit repository IDs and permission
  scopes; unscoped or duplicate repository IDs are rejected.
- Refresh occurs within five minutes of expiry, `Clear` supports revocation
  response, and no token or private-key path is written to AutoGit state.

## P2-09 — Enterprise support policy

- `Negotiate` distinguishes public GitHub from Enterprise hosts and requires
  an Enterprise version inside an explicit major-version window.
- Missing or unsupported Enterprise version metadata fails closed. The test
  matrix covers supported major/minor forms, old majors, malformed versions,
  and missing minor/version metadata.

## P2-10 — optional Check Run projection

- `PublishCheckRun` requires an exact head SHA and evidence ID, caps output and
  annotations, rejects unsafe paths/URLs, and applies AutoGit redaction before
  sending summary/text/annotation fields.
- The response is only a bounded projection result; durable AutoGit evidence
  remains authoritative.
