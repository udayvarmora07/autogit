## Acceptance mapping

### P0-01 — embedded SQLite version and durability contract

- `go.mod` pins `modernc.org/sqlite v1.58.0`.
- `internal/db/database.go` asserts embedded SQLite `3.53.4`, requires at
  least `3.51.3`, and applies the WAL, foreign-key, busy-timeout,
  synchronous, checkpoint, and single-connection contract.
- `internal/db/database_test.go` asserts the exact embedded version and
  cancellation/symlink protections; native CI covers migration, recovery,
  race, and WAL-related suites.

### P0-02 — one database opener and schema owner

- `internal/db/database.go` owns opening, pragmas, migrations, and schema
  validation.
- `internal/state/state.go` and `internal/events/events.go` route through
  `sharedDB.OpenContext`; production code has no independent shared-database
  `sql.Open` call.
- Native `go test` and race suites cover concurrent state/event projection,
  migration, recovery, and cancellation behavior.

### P0-03 — trusted filesystem and state boundaries

- `internal/securefs/securefs.go` uses `os.Root`, protected-path checks,
  no-follow validation, restrictive ownership/mode checks, WAL/SHM checks,
  and atomic fsynced writes.
- `internal/db/database.go`, `internal/verification/config.go`, and the
  secure filesystem tests cover final/component symlinks, traversal,
  replacement, and missing-path behavior on native runners.

### P0-04 — bounded hardened Git execution

- `internal/gitport/gitport.go`, `internal/gittransaction/transaction.go`,
  and `internal/repository/repository.go` use canonical executables,
  controlled environments, direct argv execution, disabled hooks/fsmonitor/
  SSH/credential helpers, and bounded output.
- Repository and provider tests cover hostile config, helper, hook, SSH,
  prompt, and linked-worktree paths; native CI executes those tests on all
  three supported operating systems.

### P0-05 — budgets, cancellation, and process-tree cleanup

- `cmd/autogit/main.go`, `internal/process/process.go`,
  `internal/verification/verification.go`, and the database/state context
  APIs propagate operation deadlines and cancellation.
- Unix process groups and the Windows Job Object
  `KILL_ON_JOB_CLOSE` boundary terminate descendants.
- `internal/process/process_tree_unix_test.go`,
  `internal/process/process_tree_windows_test.go`, cancellation tests in
  `internal/state`, `internal/events`, `internal/verification`, and bounded
  output tests provide native evidence.
